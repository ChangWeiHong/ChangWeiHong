# Profile artwork

`header.svg` and `footer.svg` are custom SVGs inspired by the smoky glass cards and dimensional illustrations in [Bento Cards v2: AI by Tran Mau Tri Tam for UI8](https://dribbble.com/shots/24297211-Bento-Cards-v2-AI). The illustrations are drawn locally; the reference's image assets are not embedded.

The header shows project files, a code editor with a pixel robot, and a reviewed code change. Its CSS animations respect reduced-motion preferences. All artwork is stored in this repository.

The [LinkedIn badge](https://img.shields.io/badge/LinkedIn-Connect-0F766E?style=flat-square&labelColor=0F172A) was generated with [Shields.io](https://shields.io/). Earlier banner drafts used [Capsule Render](https://github.com/kyechan99/capsule-render).

Copy and visual polish draw on [Hallmark](https://github.com/nutlope/hallmark/blob/main/skills/hallmark/SKILL.md) and [Stop Slop](https://github.com/hardikpandya/stop-slop/blob/main/SKILL.md).
