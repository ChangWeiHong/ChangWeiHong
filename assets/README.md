# Profile artwork

`header.svg`, `footer.svg` and `linkedin.svg` are custom SVGs drawn locally. All artwork is stored in this repository.

The header is a production line: a pixel robot builds items on a conveyor, a tests gate catches the broken ones with a red alert, and a tabby cat stamps the rest. Its CSS animations respect reduced-motion preferences.

An earlier header was inspired by [Bento Cards v2: AI by Tran Mau Tri Tam for UI8](https://dribbble.com/shots/24297211-Bento-Cards-v2-AI), and earlier banner drafts used [Capsule Render](https://github.com/kyechan99/capsule-render).

Copy and visual polish draw on [Hallmark](https://github.com/nutlope/hallmark/blob/main/skills/hallmark/SKILL.md) and [Stop Slop](https://github.com/hardikpandya/stop-slop/blob/main/SKILL.md).
